| G5 ship scope | EBOOT+data+str with QA07 and existing complete private resources for code-only test; **QA12 only if generating full new UPDATE**, PPSSPP T2 then physical Go user T3 | Broken triplet, false runtime-owner, incomplete package or missing real Go testing -> label NOT VERIFIED, no shipped success claim |

**Important nuance:** Full SEC-01 correctness cannot be established from the 20/20 QA12 abstract GE model alone. G2 requires a native implementation and verified failure-handling semantics; an arbitrary 'fail closed forever' policy may stop corruption but fail liveness.
