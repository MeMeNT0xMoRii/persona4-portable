- [`tools/psp_link.py` L128–144, L157–162, L203–228](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/tools/psp_link.py#L124-L144) uses `sorted(build/obj/*.o)`, **mutates those game object files in place with `psp-objcopy --weaken-symbol`** and populates `build/psp`, its object response file, and **`build/psp_dist/PSP/GAME/P4`**; this is not read-only linker staging. - [`tools/psp_hw_debug.py` L28–79](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/tools/psp_hw_debug.py#L28-L79) **`--out` only controls final artifact folder**. It always reads `build/psp/objects.rsp` and `build/obj` and stages copies; it rebuilds native port files, not original mirrored decomp .o. **Must call `psp_link.py` first after new decomp inventory or altered native overrides**; otherwise image/stubs/symbols and proof may be stale.
- [`tools/psp_release.py` L18–19, L37–55, L91–117](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/tools/psp_release.py#L91-L117) defines **hardcoded `DIST=build/psp_dist/PSP/GAME/P4`**. In isolated copy, clear **own** `build/obj` on a full decomp census and verify object inventory exactly matches generated mirrored source list; never delete/control-checkpoint original. `build/psp_dist` is disposable inside isolated copy. If cannot prove isolation, STOP B0 rather than build.
