## Renderer facts and local layout policies

Frozen [port/rwsky.c L1215](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/port/rwsky.c#L1215) sets target_sx = 480/640 = **0.75** and target_sy = 272/448 = **0.607142857**; [put_vertex L2888–2896](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/port/rwsky.c#L2888-L2896) applies them independently. Original logical UI is 640×448, native PSP 480×272. Nominal px=sourceX×0.75, py=sourceY×0.607142857; these are **source anchors before dynamic origin, pivot, Q12 sprite scale, animations, model camera, scissor and image/UV bounds**. Global switch to equal X/Y scale is prohibited: it would regress full-screen backdrops, menu text, fonts and many already aligned classes.

**16:9 classes:** fixed circles/eyes/faces/icons should remain proportionally fitted; right-hand party roster and date/weather cluster should be right anchored; full-screen background/bar/fade may fill or cover; layered cut-in backgrounds fill separately from cropped polygon portraits; center menus keep their own origin/row/panel/footer controls. SEC-01 GE list capacity/lifetime P0 before extra render passes. No Golden-only content or textures.
