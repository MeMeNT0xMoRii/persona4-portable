## 1. Do NOT equate screen-space 16:9 with uniform global sprite scale

Frozen PSP [`port/rwsky.c` L1211–1215](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/port/rwsky.c#L1211-L1215) sets `target_sx=480/640=0.750000`, `target_sy=272/448=0.607142857`; [`put_vertex` L2888–2896](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/port/rwsky.c#L2888-L2896) multiplies Vertex2D x/y with these factors; [`tint_sprite` L3581–3585](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/29b0fcfdec70222a4052099b67fb4a11e8d8aff4/port/rwsky.c#L3581-L3585) also uses them. A **uniform source-space circle** therefore has a native X-radius **23.529% greater than native Y-radius** in this renderer (sx/sy=21/17≈1.235294). This **does not mean the PS2's nominal 640×448 raster had square pixels or that all scene polygons are Vertex2D**. 3D/RTT, sprite pivot, screen-quad special paths, animation, font and material-specific UV may differ. All below are **pre-pivot, pre-animation base predictions, not observed screen bboxes**, except the explicitly labeled Golden/perf06 mask.

Anchor policies:
- **BL:** bottom-left wheel and its own action text, preserved readable/safe bottom rim. Keep one group pivot but permit **different transform for circle versus sprites/strip**.
- **TR:** calendar and battle roster anchored from screen top/right with responsive per-asset group layout and a measured margin, not one +X applied to every independent position.
- **C:** battle central viewport/panel stays centered; extend only full-screen decoration if necessary, preserving camera, scissor and grid spans.
- **FIT:** round indicators, icons, face/portrait quads use **uniform physical-pixel geometry** when source/asset evidence supports it; keep their own texture UV and mask transforms.
- **FILL-X:** solid/texture strips and backdrop geometry can extend horizontally to cover 480px without stretching characters or the strip's authored vertical height.
- **PANEL/TEXT:** content rows, selectable cursor strips, scrollbars, text and item icons must maintain relative alignment/spacing; do not import Golden-only row counts.
