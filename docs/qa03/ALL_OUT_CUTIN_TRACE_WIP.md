## 2026-11-19 19:00 CET — dispatch gate refinement (T1)

Pinned original [`mdlEffectFlushTreeFrame` FUN_00485870 lines 490–607](https://github.com/Raikaru/Persona4-Decompilation/blob/363eab8a966d60a9773b45f330f2344329ec4f0a/src/Graphics/Model/mdlEffect_inferred_00484bb0.c#L490-L607) verifies a **conditional per-child draw gate**: the root returns when `frame<=0`; a child is skipped when `root->frame-1 < child->startFrame` or `child->flags & 2`. Only eligible children dispatch the draw callback at `D_00713480 + (primitive->kind << 6) + 0x0C`. Position callback `+0x20` runs only for child flags `0x18` and rotation `+0x24` only for `0x60`; both callbacks are optional, unlike the invoked draw slot. This means **logging all allocated children would misidentify visible All-Out layers**. Capture *eligible/drawn* children with frame, flags, kind and instance handle, then join to resource ID and final bbox/UV.

Pinned [`include/mdl_effect_dispatch_internal.h`](https://github.com/Raikaru/Persona4-Decompilation/blob/363eab8a966d60a9773b45f330f2344329ec4f0a/include/mdl_effect_dispatch_internal.h) confirms 0x40-byte per-kind handler entries but **only constructor/clone/destructor are typed**. The exact numeric kind→draw implementation and any All-Out-specific kind are **not resolved**. GitHub code search currently indexes a *different default-branch revision* (`3a281400...`), so its hits must **not** be cited as pinned evidence; direct `fetch_file` at `363eab8a...` was used here.
