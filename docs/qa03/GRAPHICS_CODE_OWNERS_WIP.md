## 5. Glowing orbs, fusion particles, sky/title crossfades — distinct renderer effects

- [`port/rwsky.c` L3495–3554](https://github.com/MeMeNT0xMoRii/persona4-portable/blob/dev/v0.27-perf06/port/rwsky.c#L3495) maps GS alpha-only writes and destination-alpha reads onto GE stencil/masks; `p4_effect_mask`, `p4_alpha_pixel`, `p4_dst_alpha_passes` and the `sky_state[3]==0x31001` path gate behavior.
- This is directly relevant **as an architectural candidate** for reported square/bright orb effects (fusion / Zio / title), NOT proof that those effects share the same primitive/texture. Some small destination-alpha passes are intentionally skipped to suppress invalid blobs; changing that global branch can alter lighting or break fullscreen effects/perf.
- **Test design:** sample matched before/after pass properties (`raster`, blend, alpha-test, pixel mask, UV, draw area, depth state, fill cost) for a **single reproducible Zio frame** and **single Apsaras fusion frame**. Compare whether the first incorrect pass is a mask writer or overlay reader. No scene-wide disable of fog/particles just to hide a bug.
- Previously researched b383 Igor-table backface culling and b386 Fusion-card Im3D faces remain **separate** candidate render paths. Do not merge these issues without evidence. See [existing hardware comparison](../v027_qa03_b388_vs_perf06_hardware_2026-11-19.md).
