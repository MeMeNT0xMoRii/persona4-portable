## Model selection for this project, with limits

- **Default if actually available: GPT-6.2 Sol, Medium effort, Standard speed** in Codex. The work is already source-scoped and test-plan-rich; spending a higher-reasoning model on copying the 200KB Handoff or updating markdown is not justified. If absent, choose a currently available Sol variant; **do not infer the user's selector or remaining allowance** from this document.
- **Escalate selectively:** GPT-6.2 Astra Medium for an independent review of the GE two-bank lifetime/SDK inline emitter safety, difficult pointer ownership, a reproduced race or a failed Sol design with an exact minimal test. Use High/Extra High only after a concrete failure or missing invariant is identified, and supply the actual failing build/test/log. If the problem is missing private ISO, Windows PSPDEV, Golden ZIP or a real PSP-Go observation, **model escalation cannot resolve it**.
- **Avoid Fast/Ultrafast for ordinary Saturday tasks** unless an explicit observed deadline justifies extra usage and the user's plan supports it. Reasoning level and speed can change consumed allowance. The exact model, effort and speed controls differ between Work, Codex desktop/CLI and regular Chat.
- **No fixed 80/20 spending ratio:** 80% Sol tasks / 20% Astra tasks is at most a count-of-task heuristic and could spend much more on Astra tokens. Start with a small Sol task, inspect actual usage, then reserve Astra for one code-risk decision and final review where it materially helps.

## Credit-efficient execution order — one scope at a time

1. **B0 Sol Medium:** [short canonical startup](CODEX_START_HERE_RESONANCE01_2026-11-21.md); verify pinned source, Windows `psp-gcc.exe` toolchain/user-owned ISO private availability, actual perf06 artifact SHA and save clones. Verify current source branch and local compiler **before long edits**. If unavailable, return blocker and only work on source/host tasks that can actually be tested.
2. **SEC-01 Sol Medium; selective Astra review:** design atomic list writer budgets for raw P4P and **inlined PSPSDK** GU paths, reserve FINISH/END, prove GE pending bank does not get overwritten after watchdog failure. Generate small host pressure/retirement tests first. Only one independent Astra Medium review when there is a concrete design/diff to critique.
3. **D1 Sol Medium:** integrate the Flight Recorder 512×64B test model with **independent verified binary write/rename/ACK**, not the old text logger `log_tail=head` after failed file write; measure instrumentation overhead. No per-primitive blocking disk writes.
4. **UI/perf Sol Medium:** first isolated command-wheel fan geometry or one measured scene-specific renderer bottleneck, with exact source owner and before/after accepted-display p50/p95/p99. Full Golden 120 reference is private and may not be accessible in Codex. Only perform other UI changes with adequate matched evidence.
5. **STAB/IO Sol Medium:** focus on pre-deref Compendium ID/cache and edited-save clones, reinforcement task/GE/IO last-progress markers, or actual linked package cursor; do not brute-force theoretical issues in parallel as if all were reproduced.
6. **Fusion optional EXP:** clean-room manual inheritance only behind OFF-by-default experimental feature, validate original YES, normal/triangle/multi, accidents, skill legality, cancel and save; historical host 18/18 is synthetic and not native PSP proof.
7. **Final QA Sol Medium + optional narrow Astra review:** full artifact and feature flag manifests, host and real PPSSPP results, PSP Go tester G00–G19 card, last good commit, explicit FAILED/NOT RUN; inspect user-facing artifact only if actually built. Do not spend Astra re-summarizing the 1.47MB archive.

### Minimal Codex task envelope (reusable)

**Input:** current issue ID + pinned original/PSP function + real symptom or falsifiable source hazard + exact relevant file paths + one acceptance test and one negative control. **Work:** smallest reversible patch, host tests, linked PSP symbol check, PPSSPP if possible. **Output:** changed lines, test commands and raw PASS/FAIL/NOT RUN, actual profile hash and rollback. **Stop/continue:** pause that issue when evidence or a private toolchain is absent; pursue a different source-only subtask if independent. Never relaunch the whole masterprompt or reread the entire historical Handoff to fix a small compiler error.

**Billing caution:** do not automatically change subscription/credit purchases or reload settings. Record usage only when visible in the actual account; no assistant or generic GitHub repo knows the user's balance. Codex can access and build private local inputs only when its selected environment and permissions actually provide them.
